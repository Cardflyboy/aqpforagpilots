# aqpforagpilots.com

Static site for AQP for Ag Pilots (George Parker III, Crop Jet Aviation).
Deployed on Cloudflare Workers (static assets) via Workers Builds — push to `main` deploys.

- `site/index.html` — the whole site, single file
- `wrangler.jsonc` — Workers config with custom domains

Every fact on the page traces to a source listed in the page footer. Keep it that way.
